# PoseGuard Workflow

## 전체 시스템 실행 흐름

1. 사용자가 프로그램을 실행한다.

2. OpenCV를 통해 웹캠 영상을 입력받는다.

3. MediaPipe를 사용하여 사용자의 관절 좌표를 추출한다.

4. 추출된 좌표 데이터를 pose_data 형식으로 저장한다.

5. 자세 분석 로직을 통해 거북목 여부 및 목 각도를 계산한다.

6. 잘못된 자세가 일정 시간 이상 지속되면 경고 팝업을 출력한다.

7. 반복적으로 자세 이상이 감지되면 스트레칭 가이드를 제공한다.

8. 세션 종료 시 자세 유지율 및 알림 횟수를 계산한다.

9. 결과 데이터를 Firebase에 저장한다.

10. Matplotlib을 통해 자세 변화 그래프를 출력한다.

11. Gemini API를 활용하여 사용자 맞춤형 건강 코멘트를 생성한다.
